1. 容器数据类型
    列表 list
        有序
            列表中的元素都有对应的下标(索引), 可以通过下标操作列表元素
        可变
        list1 = [1, 20 , 3]  --> list1 = [2, 10, 4]
        可重复
        可存放不同类型元素
        使用[] 定义列表

    字符串 str
        有序
            字符串中元素(字符)都有对应的下标
        不可变
            str1 = "hello"
            可以变为 str2 = "world"  可以重新指向另一个对象,
            但是不能直接对字符串中字符修改. 修改会创建新对象.
        字符串中不能存放不同类型元素, 只能放字符
        字符串定义:
            单引号 ''
            双引号 ""
            三引号 """ """ 保留格式进行输出


    元组 tuple
        有序的
            通过下标访问元组中的元素
        元组是不可变的
            不能对元组中的元素进行修改
        元组中元素是可以重复的
        元组中可以存放不同类型

    集合 set
        集合set是无序的
            无序没有下标
        set是可变的
        set中的元素不能重复
        set可以存储不同类型
        集合set使用{}定义
        如果定义空集合, 不能直接使用{}, 需要使用set()


    字典 dict
        以k-v 键值对的形式存放数据
        字典是无序的, 但是python3.7 之后, 保持插入顺序
        key 不能重复, value 可以重复
        key 不可变类型， value可变
        通过key获取value
            定义字典 {}: k和v这之间用:分割, 多个键值对之间用,分隔

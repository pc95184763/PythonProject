
1 函数参数传递的形式
    必须参数
        按照位置对实参和形参进行匹配, 要求实参和形参的参数个数必须要一致.
    关键字参数
        按照名称对实参和形参进行匹配, 要求调用函数的时候指定的名称和形参名

    默认值参数
        可以在声明形参的时候，指定默认值
        可以简化参数的传递，在调用函数的时候，指定了默认值的参数可以不用传参
        在调用函数的时候，如果没有给指定了默认值的形参传递实参的话, 那么使用默认值; 如果传递了实参，则用实参
        注意：在声明函数的时候，非默认值参数必须要放到默认值参数前面
    不定长参数(可变长参数)
        在定义函数的时候, 使用一个*或者**修饰形式参数
        如果一个*，底层是用元组接收处理多个参数的，后面可以跟普通参数，要求调用的时候，可变长后面参数用关键字传递
        如果一个**，底层是用字典接收处理多个参数的，后面不能跟普通参数


2. 解包传参
    将元组或者字典中的元素拆解出来，作为实参传递给函数
    语法:
        函数名(*元组) ---要求元组中元素的个数和形参的个数必须一致
        函数名(**字典) ---要求字典中的key和形参的名字必须一致


3. 深拷贝和浅拷贝
    浅拷贝:拷贝父对象, 不会拷贝对象的内部的子对象.拷贝后只有第一层独立
        [:]
        copy.copy()
    深拷贝: 完全拷贝父对象及其子对象。拷贝后所有层都是独立的
        copy.deepcopy()

4.return
    结束当前正在进行的函数, 返回到函数调用位置
    给调用者返回当前的计算结果


5. 变量作用域  ()
    Local局部作用域
    Enclosing 嵌套作用域
    Global 全局作用域
    Builtin 内建作用域
    在查找的时候, 会按照如下顺序进行查找: 局部 -> 嵌套 -> 全局 -> 内建

    只有模块module, 类 class, 以及函数 def, lambda 才会引入新的作用域,
    其他的代码块(if/elif, try/except, for/while) 不会引入新的作用域
